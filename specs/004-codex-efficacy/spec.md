# Milestone 4: Codex efficacy baseline

**Status:** Completed; no productivity or cost benefit established.

## Goal

Compare Codex sessions with and without Laya integration using matched tasks and report actual time and token use, while separating estimates from billed cost.

## Outcome

The first five-prompt comparison showed 25.2% more total tokens and 33.3% longer median wall time with Laya enabled. These prompts measured tool availability more than coding quality. The result justified a deeper paired coding evaluation in [Milestone 5](../005-measurable-efficiency/spec.md), not a savings claim. Evidence: [Codex efficacy report](../../docs/codex-efficacy-baseline.md).
